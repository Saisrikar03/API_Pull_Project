PROJECT OVERVIEW

* This project demonstrates how to automate data extraction from a cryptocurrency website API using Python.
* It focuses on pulling live crypto data, processing it, and preparing it for analysis.

OBJECTIVE

* To learn API handling, automation, and basic data manipulation using Python in a real-world use case.

TOOLS USED

* Python

* Requests

* Pandas

* Jupyter Notebook

WHAT THIS PROJECT DOES

* Connects to a cryptocurrency API

* Fetches real-time crypto market data

* Converts API responses into structured data

* Stores and analyzes data using Pandas

FILES INCLUDED

* Jupyter Notebook containing full implementation

* Python code for API automation and data handling

SKILLS DEMONSTRATED

* API integration

* Data extraction and automation

* Data cleaning and transformation

* Python programming for data analysis
